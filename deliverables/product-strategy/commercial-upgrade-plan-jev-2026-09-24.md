## 📌 TL;DR（执行摘要，3-5 行）

- **核心目标**：把 v0.1.0「自用工具」升级为可合法销售的商品，分 **v0.5 商业化最小可售卖版（补齐外壳）→ v1.0 付费正式版（含免 Key 订阅）→ v2 储备** 三阶段推进。
- **关键决策**：差距 100% 在**商业化外壳**（授权/计费/合规/品牌/分发），**分析内核已通、不要重写**；采用「**先 Key 后内置**」两阶段，先自备 API Key 控风险，验证付费意愿后再上厂商代付订阅消除 Key 门槛；定价「**买断/终身为主（199–399 元）+ 低价订阅为辅（30–80 元/月）**」。
- **差异化定位**：以「**不读微信数据库 + 本地隐私 + 结构化话术卡**」三件套，对冲 MemoTrace（免费读库）与 ChatGPT iMessage 原生分析威胁；把隐私从前提变成**首屏卖点**。
- **下一步**：立即启动 v0.5 的 P0 五件事（≈22 人日），打通「下载→激活→试用」漏斗。

## 1. 产品目标（3 个清晰、正交的目标 · 来自析客）

- **G1 商业化可售卖（供给侧/外壳）**：从自用脚本转为「可合法销售、可安装、可更新」的正式软件。补齐授权激活、合规文档、分发渠道、支持体系、品牌定位五大缺失外壳。
- **G2 转化闭环打通（需求侧/付费）**：消除「自备 API Key」这一最大转化拦路虎。通过免费试用额度 / 免 Key 体验档 + 厂商代付订阅，跑通「安装→激活→首单付费」，达成试用→付费 3%–8%、D7 留存 >30%。
- **G3 隐私品牌心智（定位侧/信任）**：以「本地优先 / 开源可审计 / 记录不出本机 / 不读微信数据库」为第一卖点占领信任心智，与读库竞品、PUA 情感咨询 App 明确切割。

三者正交：G1 解决「能不能卖」，G2 解决「能不能付费」，G3 解决「凭什么信你」。

## 2. 用户研究洞察（来自瑞思）

- **U1 「自备 API Key」是规模化最大拦路虎**：会锁死商业化规模，必须提供「免配 Key / 内置额度」付费档，否则转化率天花板极低。
- **U2 隐私是双刃剑，需前置为首屏卖点**：2026-09「微信 AI 隐私」热搜背景下，把「本地优先 / 开源可审计 / 记录不出本机」放在第一屏，是建立信任的最高 ROI 动作。
- **U3 定价切入「几十元订阅 + 免费额度」，避开千元情感导师区**：用低客单降低决策门槛；开源社区（狗头军师一周涨千星）是现成冷启动流量。
- **U4 促成首单的信任证据链**：开源透明 + 免费额度 + 脱敏真实案例 + 退款保证 + 明确「不承诺包挽回」并与 PUA 切割，五者共同构成转化临门一脚。
- **核心付费人群**：20–30 岁暧昧/恋爱期男性（约会付费男女 ≈ 9:1）；第二梯队为挽回/复合人群（最愿花钱也最警惕骗局）；关系焦虑者需「情绪承接」差异化；销售 B 端/自媒体是边缘（后者是渠道不是消费者）。

## 4. 数据依据（来自数析）

- **就绪度结论**：8 维度评估仅 1 就绪、2 部分、5 缺失，**缺失项 100% 集中在商业化外壳**（授权/计费/合规/品牌/分发），功能本身不是瓶颈。
- **API 成本测算**：单次分析 ≈ 0.02 元，活跃用户月成本 ≤ 2 元，占合理订阅价 < 5% → **厂商代付在商业上可行**。建议「先 Key 后内置」两阶段：冷启动用自备 Key 控风险，验证付费意愿后推厂商代付/内置额度订阅拉升转化。
- **合规判定**：产品已具备本地优先、隐私门、不打包敏感目录（PIPL 雏形），缺的是**隐私政策、用户协议、微信数据条款三份文档 + 显著告知**——属「文书+告知」问题，成本低、风险高，须 P0 完成。
- **定价锚点**：国内桌面 AI 工具买断/终身 199–399 元（XMind 终身 399）、订阅 30–80 元/月。建议**买断/终身为主 + 低价订阅为辅**，规避订阅焦虑与「割韭菜」印象。
- **核心监控指标**：安装激活率 >40%、7 日完整分析闭环 >50%、试用→付费 3%–8%、D7 留存 >30%、单用户 API 成本 ≤2 元/月、退款率 <5%。

**就绪度 8 维度评分（满分 5）**：功能完整性 4 / 授权激活 1 / 法律合规 1 / 安装分发 1 / 试用体验 0 / 订阅计费 0 / 品牌获客 0 / 数据监控 1。

## 7. 关键流程 / 首屏设计（来自析客）

**激活与付费流程**
```
[首次启动] → [隐私声明+用户协议 勾选] ─拒绝─▶ 退出
                   │ 接受
                   ▼
        [选择档位: 试用(免Key) │ 买断 │ 订阅]
         ├─ 试用 ─▶ [发放免费额度] ─▶ [主界面, ≥1 次完整分析]
         ├─ 买断 ─▶ [输入许可证密钥] ─┬ 通过 ─▶ [永久激活]
         │                          └ 失败 ─▶ [保留试用档]
         └─ 订阅 ─▶ [支付] ─▶ [绑定账户+内置额度] ─▶ [免 Key 分析]
```

**首屏「隐私卖点」布局**：顶部品牌名 + 一句话定位（「你的聊天记录，只属于你」）；主视觉三卡「本地优先 / 开源可审计 / 记录不出本机」；副文案强切割「不读微信数据库 · 不自动发信 · 不承诺包挽回」；CTA 双按钮 `[免费试用]`（主）/ `[购买买断版]`（次）；底部隐私政策/用户协议链接 + 开源仓库入口。

**付费档位（v1.0）**：免费档（免 Key 体验 ≤1 次完整分析）；买断档（199–399 元，永久激活，控风险期需自备 Key）；订阅档（30–80 元/月，厂商代付内置额度，彻底免 Key，到期降级试用）。

## 8. Non-goals（明确不做什么）

- **不读微信本地数据库、不解密**：坚持截图+OCR 入口，这是隐私卖点根基。
- **不自动发信**：仅分析与建议，绝不代发消息。
- **不承诺「包挽回/包脱单」**：明确与 PUA、情感导师切割，仅提供分析工具。
- **不做心理/医疗诊断**：非诊疗产品，关系焦虑者仅做情绪承接式引导。
- **v1.0 不做群聊分析、不做跨平台（Mac/Linux）**：列入 v2。
- **v1.0 不上架需抽成的第三方应用商店内购**：避免与买断定价冲突（待确认）。

## 9. 利益相关者沟通要点（来自路径，三视图）

- **高管视图**：一句话战略 = 先补商业化外壳、不堆功能（内核已通、功能非瓶颈，差距 100% 在变现闭环）。营收预期：v0.5 打通下载→激活→试用漏斗；v1.0 以厂商代付消除 Key 摩擦，目标试用→付费 3%–8%、D7 留存 >30%。关键赌注：厂商代付能否在毛利内兜底（已证 ≤2 元/月可行）、隐私卖点能否对冲 MemoTrace/ChatGPT 原生威胁。
- **工程视图**：v0.5 聚焦打包/签名/自动更新 + 授权激活 + 隐私告知 + 试用额度四类外壳模块；**勿动分析内核**；改造点 = 安装器与代码签名、激活校验服务、试用配额服务、v1.0 代付结算对接；风险 = 签名证书采购周期、激活服务可用性与防破解平衡。
- **设计/市场视图**：首屏把「本地分析·不读微信数据库·隐私优先」作为第一信任锚；v1.0 落地页**必须含隐私对比页**（vs MemoTrace 读库 / ChatGPT 原生）作转化钩子；内容获客素材随案例同步产出，借开源社区冷启动，走「内容+社区」驱动获客。
