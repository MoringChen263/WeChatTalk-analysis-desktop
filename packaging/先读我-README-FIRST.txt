狗头军师 · 微信对话分析台  v0.1.0
================================================
         先 读 我（5 分钟就能用起来）
================================================

【这是个什么工具】

一个 Windows 桌面小工具。它做三件事：

  1. 盯着你电脑上的微信聊天窗口，截图后在本机识别成文字；
  2. 把这段对话交给 AI 分析（心动、暧昧、聊天记录解读、
     投入是否失衡、要不要摊牌……）；
  3. 给出一份分析和可以直接复制发送的话术。

分析思路来自开源项目「狗头军师」，这个工具把它做成了图形界面。


------------------------------------------------
【第一步：启动】
------------------------------------------------

1) 把解压出来的整个文件夹放到你喜欢的位置（比如 D:\狗头军师\）。

   ⚠ 必须整个文件夹一起用，只把 exe 拷出来是打不开的。
     程序旁边那个 _internal 文件夹是它的运行库，不能丢。

2) 双击文件夹里的   jev-chat-analyzer.exe

3) 如果弹出蓝色的「Windows 已保护你的电脑」：
   这是因为程序没有购买数字签名证书（个人项目一般不买），
   并不是中毒。点「更多信息」→「仍要运行」即可。

4) 看到标题是「狗头军师 · 微信对话分析台 v0.1.0」的窗口，就成了。

   首次启动约 5~15 秒（要加载识别模型），之后会快一些。


------------------------------------------------
【第二步：配 API Key（第一次必须做）】
------------------------------------------------

这个工具本身不含 AI，需要调用大模型服务。默认接的是 DeepSeek。

  a) 打开 https://platform.deepseek.com  注册并登录
  b) 在「API Keys」里创建一个 Key，形如 sk-xxxxxxxxxxxxxxxx
  c) 在「充值」页面充一点余额（按用量计费；
     实测分析一次完整对话约 0.05 元，充 10 元能用很久）
  d) 回到程序 → 点左下角的「设置」
  e) 把 Key 粘到「API Key」那一栏 → 点「保存到本机凭据」
  f) 再点「测试连接」，提示成功就配好了

关于这把 Key：
  · 它只会用 Windows 自带的 DPAPI 加密后存在你自己电脑上
    （C:\Users\你的用户名\AppData\Roaming\jev-chat-analyzer\config.json）
  · 文件里只有密文，不落明文，也不会被发到任何地方
  · 换了电脑要重新填一次

不想用 DeepSeek 也行：
  设置页的 base_url 和「模型」可以改成任何 OpenAI 兼容的服务
  （你自己的中转站、硅基流动、Kimi 之类），改完点「拉取模型列表」
  就能看到对方支持的模型。但要注意 —— 换服务商等于换了一家接收你
  聊天内容的地方，请自己判断是否可信。


------------------------------------------------
【第三步：怎么用】
------------------------------------------------

1) 电脑上打开微信，进入你要分析的那个聊天窗口，让它显示在屏幕上。
2) 程序左侧点「重新扫描」，在下拉框里选中微信窗口。
3) 点「开始监控」，程序会定时截图并在本机识别文字。
4) 看够了点「停止」。
5) 在「导入聊天记录…」旁边的文字区检查识别结果。
   关键一步：确认「我 = 右侧」还是「我 = 左侧」，也就是
   对话里哪一边是你。搞错了 AI 会把你们俩的身份弄反。
6) 右侧点「开始分析」，等 10~30 秒。
7) 结果出来后：
      · 「复制全文」整份拷走
      · 话术卡上的「复制当前这版」拷某一句话
      · 「导出 analysis.json」存一份结构化结果

「档案」页可以开启长期记忆：让 AI 记住这个人的背景，
下次分析时自动带上。默认是关的，开的时候会弹一次说明让你确认。
记忆库只存在你本机。


------------------------------------------------
【隐私提示，请务必读一下】
------------------------------------------------

· 截图和文字识别（OCR）全部在你电脑上完成，图片不会离开本机。

· 但分析的时候，识别出来的聊天文字会通过网络发送给模型服务商
  （默认是 DeepSeek）。这是所有这类工具的必然代价，没有例外。

· 所以：分析别人的聊天记录之前，请先取得对方同意。
  把别人的聊天内容发给第三方服务，这件事涉及的是别人的隐私。

· 想彻底清干净：程序里关掉记忆功能，然后删掉
  C:\Users\你的用户名\AppData\Roaming\jev-chat-analyzer\ 整个文件夹。


------------------------------------------------
【出问题了怎么查】
------------------------------------------------

· 双击没反应 / 闪一下就不见：
  打开 C:\Users\你的用户名\AppData\Roaming\jev-chat-analyzer\logs\app.log
  看最后几行，那里会有原因。（程序不会静默失败，一定留下了记录。）

· 想确认程序本身是否完好：
  在程序所在文件夹按住 Shift + 右键 →「在此处打开终端」→ 执行

      jev-chat-analyzer.exe --selftest

  跑完看 %APPDATA%\jev-chat-analyzer\selftest.txt，
  出现「全部通过」说明程序完好，问题在配置或环境。

· 识别不出字：把微信窗口拉大一点、聊天字号调大一点再试。
  窗口太小或系统缩放异常会影响识别率。

· 分析报「结构化输出失败」：模型偶尔会把格式写错，程序会自动重试
  一次。连续失败通常是 Key 余额不足、或模型名填错了。

· 想换模型：设置页「模型」里填 deepseek-chat 即可。
  注意 DeepSeek 的两个新模型（deepseek-flash / deepseek-v4-pro）
  是推理型，会先输出一段思考，费用略高、也略慢，但质量更稳。


------------------------------------------------
【运行环境】
------------------------------------------------

· Windows 10（1903 及以上）或 Windows 11，64 位
  —— 采集用的是系统自带的屏幕捕获接口，太老的系统没有。
· 不需要装 Python，也不需要装任何运行库，解压即用。
· 采集功能需要微信 PC 版（Weixin.exe / WeChat.exe）。
  只做文字导入分析的话，不装微信也能用。


------------------------------------------------
【卸载】
------------------------------------------------

删掉程序文件夹，再删掉
C:\Users\你的用户名\AppData\Roaming\jev-chat-analyzer\
即可，没有注册表残留、没有后台服务。
